Why This Exact Order?

ANN First — Minimal New Concepts

Your Random Forest takes a feature vector and classifies it. An ANN does the same thing — just with learned linear combinations and non-linear activations instead of decision tree splits. The input (bearing_features_phase3.csv) is identical. You only need to learn: Dense layers, ReLU, Softmax, Adam, categorical cross-entropy. That's 5 new concepts, not 50.

CNN Second — Feature Learning Revolution

ANN taught you that neural networks can classify. CNN raises the question: do you even need to engineer features?A 1D CNN slides a filter over the raw 15, 625-sample vibration signal and automatically learns what kurtosis, envelope peak, and peak-to-peak represent — without you writing a single feature formula.

Raw signalAuto featuresConvolution
RNN Third — Temporal Dependency

CNN treats the signal as a spatial pattern (slide filter left-right). RNN treats it as a sequence— sample at time t depends on samples at t-1, t-2... This matters for vibration: IR fault creates a spike every N samples (periodically), and RNN can learn to track "I saw a spike 120 samples ago." Introduces: hidden state, unrolling, BPTT.

SequenceMemoryBPTT
LSTM Last — Solving RNN's Problem

RNN forgets long-range dependencies (vanishing gradient). Your bearing signal is 1 second=15, 625 samples. An IR fault spike appears every~93 samples (at 1000 RPM). RNN loses memory of that spike by the time it sees the next one. LSTM's cell state remembers it. Understand gates before applying them.

Key Concepts — Before the Code

StandardScaler — Why First

Your kurtosis ranges 0.25 → 172. Your mean ranges −0.003 →+0.001. Without scaling, kurtosis dominates every weight update. Gradient descent steps are proportional to feature magnitude. StandardScaler normalizes each feature to mean=0, std=1 — all features contribute equally.

x_scaled=(x − μ_train) / σ_train

CRITICAL: Fit scaler on train only. Transform test with same scaler.
Never fit on test — this is data leakage.
Label Encoding → One-Hot

Your fault column: ['OK', 'IR', 'OR', 'RE']. Neural networks need numbers. Two steps: (1) LabelEncoder → [0, 1, 2, 3]. (2) to_categorical → one-hot vectors. IR=[0, 1, 0, 0]. This pairs with Softmax+Categorical Cross-Entropy.

OK → [1, 0, 0, 0]
IR → [0, 1, 0, 0]
OR → [0, 0, 1, 0]
RE → [0, 0, 0, 1]

Loss=−Σ yᵢ · log(ŷᵢ) → only correct class term survives

Mathematical Intuition

Forward Pass for One Sample

Input: x=[RMS, Kurtosis, Peak, ..., Skewness] shape:(9, )

Layer 1: z₁=W₁·x+b₁ W₁ shape: (64, 9)
a₁=ReLU(z₁) shape: (64, )

Layer 2: z₂=W₂·a₁+b₂ W₂ shape: (32, 64)
a₂=ReLU(z₂) shape: (32, )

Output: z₃=W₃·a₂+b₃ W₃ shape: (4, 32)
ŷ=Softmax(z₃) shape: (4, )

Loss: L=−Σ yᵢ·log(ŷᵢ) → only IR term survives if true=IR

Adam Optimizer vs SGD

SGD: w=w − η·∂L/∂w (same lr for everything)

Adam: mₜ=β₁·mₜ₋₁+(1−β₁)·gₜ (momentum)
vₜ=β₂·vₜ₋₁+(1−β₂)·gₜ² (velocity)
m̂ₜ=mₜ/(1−β₁ᵗ) v̂ₜ=vₜ/(1−β₂ᵗ)
w=w − η·m̂ₜ/√(v̂ₜ+ε)

Defaults: β₁=0.9, β₂=0.999, ε=1e-8
Benefit: lr adapts per weight → faster convergence
🧠
Why ANN Won't Beat Your Random Forest (Probably)
With 240 training samples and 9 features, Random Forest wins. ANN has 2, 852 parameters — that's 12× the training data count. It will overfit unless heavily regularized. The lesson: ANN shines when data is large and features are raw/unstructured. With your carefully engineered features, RF' s tree-based splits are more data-efficient.

How 1D Convolution Works on Vibration

💡
Convolution Intuition
Imagine a 16-point sliding window moving along your 15, 625-sample vibration signal. At each position, it computes a dot product with a learned weight vector (kernel). If the signal matches the kernel pattern → high output. If not → near zero. After training, some kernels look like "spike detectors"(learning what you computed as kurtosis manually).
Output at position t: y[t]=Σₖ x[t+k]·w[k]+bfor k=0..K-1

Signal: x has shape (15625, 1)
Kernel: w has shape (kernel_size, 1, n_filters)
Output: shape (15625 - kernel_size + 1, n_filters)

After MaxPool(2): output length halved → compresses signal

Task 4 — RNN Implementation
Simple RNN— Sequential Memory for Vibration
Treat the vibration signal as a time series. Each sample depends on what came before. Introduces hidden state — the RNN's memory mechanism.

Why RNN? — Sequential Dependency in Vibration

The Problem CNN Ignores

CNN looks at local patterns (64-sample window). It detects "there is a spike here." But it ignores: when was the last spike?For IR fault at 1000 RPM, spikes repeat every~93 samples. CNN detects each spike independently. RNN can learn: "spike → 93 samples → spike → 93 samples"=IR pattern.

The Hidden State Concept

At every timestep t, the RNN maintains a hidden statehₜ — a compressed memory of everything seen so far. hₜ=f(xₜ, hₜ₋₁). This hidden state passes information forward through time.

hₜ=tanh(Wₓ·xₜ + Wₕ·hₜ₋₁ + b)

Wₓ: input weights Wₕ: recurrent weights
Same weights used at EVERY timestep (weight sharing)

The Vanishing Gradient Problem

🚨
Why Simple RNN Fails for Long Sequences
During backpropagation through time (BPTT), gradients are multiplied by Wₕ at every step. If |eigenvalue(Wₕ)| < 1 → gradients vanish after~10 steps. Your IR spike period is 93 steps. RNN cannot learn that the spike 93 steps ago caused this spike. This is why LSTM was invented.
Gradient at step t-k: ∂hₜ/∂hₜ₋ₖ=Π (∂hₜ₋ᵢ/∂hₜ₋ᵢ₋₁)
i=1..k

≈ Wₕᵏ · Π f'(hₜ₋ᵢ)

If ||Wₕ|| < 1: → 0 (vanishing) after k steps
If ||Wₕ|| > 1: → ∞ (exploding) after k steps

Task 5 — LSTM Implementation
LSTM— Long Short-Term Memory
LSTM adds a dedicated memory line (cell state) and three gates that control what to remember, forget, and output. Directly solves the vanishing gradient that broke SimpleRNN on your IR fault periodicity.

The Four Gates — Complete Explanation

🔴 Forget Gate — What to Erase
fₜ=σ(Wf·[hₜ₋₁, xₜ] + bf)
Output: fₜ ∈ (0, 1) for each cell state dimension. fₜ≈0 → forget completely. fₜ≈1 → keep exactly. Applied to cell state: Cₜ' = fₜ ⊙ Cₜ₋₁. Bearing analogy: When OR fault pattern changes, forget gate erases the old IR pattern from memory.
🟢 Input Gate — What to Write
iₜ=σ(Wᵢ·[hₜ₋₁, xₜ] + bᵢ) (how much to write)
C̃ₜ=tanh(Wc·[hₜ₋₁, xₜ] + bc) (candidate values)
New cell content: Cₜ=fₜ⊙Cₜ₋₁+iₜ⊙C̃ₜ. iₜ selects which dimensions to update. C̃ₜ provides the candidate values. Bearing analogy:When a new IR spike arrives, the input gate writes "spike occurred at this timestep" into cell state.
🔵 Cell State — The Memory Highway
Cₜ=fₜ ⊙ Cₜ₋₁+iₜ ⊙ C̃ₜ
The cell state Cₜ flows through the entire sequence with only two simple operations: element-wise multiplication (forget) and addition (input). No non-linearity on the main path— this is why gradients don't vanish! The gradient of Cₜ w.r.t. Cₜ₋₁ = fₜ ≈ 1 → gradient preserved over long sequences. Bearing: remembers spike interval = 93 samples.
🟡 Output Gate — What to Read
oₜ=σ(Wo·[hₜ₋₁, xₜ] + bo)
hₜ=oₜ ⊙ tanh(Cₜ)
oₜ decides which parts of cell state to expose as hidden state hₜ. hₜ is passed to the next timestep AND used for prediction. Bearing analogy:At the end of the window, output gate extracts "IR fault detected with periodicity 93" from cell state as the classification signal.

Why LSTM Fixes Vanishing Gradient

SimpleRNN Gradient
∂L/∂hₜ₋ₖ=∂L/∂hₜ · (Wₕ·diag(f'(h)))ᵏ

= product of k matrices

If ||Wₕ·diag(f')|| < 1 → exponential decay
After 93 steps: almost zero → IR period forgotten
LSTM Cell State Gradient
∂Cₜ/∂Cₜ₋₁=fₜ (forget gate value)

∂L/∂Cₜ₋ₖ ≈ ∂L/∂Cₜ · Π fₜ₋ᵢ
i=1..k

When fₜ ≈ 1 (keep memory): gradient ≈ 1 for all k
No vanishing ! IR period (93 steps) preserved.

Decision Framework — Which Model When?

Use Random Forest / XGBoost when:
  • Dataset < 5K samples (like your 300 recordings)
  • Features have physical meaning (kurtosis=IR fault detector)
  • Interpretability required (maintenance engineers need explanations)
  • Fast inference needed (edge deployment, real-time monitoring)
  • No GPU available
Use 1D CNN when:
  • Raw signal data available, dataset large (10K+ recordings or windowed)
  • Feature engineering bottleneck (hard to know what features to extract)
  • Multiple sensor channels (multichannel convolution)
  • Speed matters at inference (fast after training)
  • Pattern location matters (translational invariance needed)
Use LSTM when:
  • Long-range temporal dependencies matter (IR spike periodicity)
  • Variable-length sequences (different recording durations)
  • Prediction task (predict next N samples — anomaly detection)
  • Sequence classification where order critically matters
Use CNN-LSTM Hybrid when:
  • Need both local pattern detection (CNN) AND temporal tracking (LSTM)
  • Best of both worlds: CNN extracts features, LSTM classifies over time
  • Architecture: Conv → Pool → LSTM → Dense
  • This is the state-of-art for industrial fault diagnosis
